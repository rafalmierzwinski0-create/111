Every picture below is the plugin itself, on a real WordPress site. Nothing is drawn or mocked up.

01

You see the table before you save it

Paste the link to your sheet and choose Load preview. The plugin reads the sheet and shows exactly what it found — how many rows, how many columns, what the headings are. If the sheet is wrong, you find out now, not after it is on your page.The screen also tells you what a narrow column will do to the table, before you commit to it.

WordPress › Live Sheets Table

02

Every sheet in one list

Each sheet gets a card: whether it is up to date, how many rows it has, how often it is checked, and which page it is used on. The shortcode sits there with a copy button, so putting the table anywhere takes one click.

WordPress › Sheet sources

03

The table on your page

Search, sortable headings and a line saying how fresh the data is. It is a real table in the page code, not an embedded frame, so Google sees it and so do people using a screen reader.

yoursite.com/price-list

04

On a phone it folds into cards

A wide table does not fit a phone, so each row becomes a card and every value keeps the name of its column. What decides is the width of the column the table sits in, not the width of the screen — so a table in a narrow sidebar folds on a desktop too.

yoursite.com — phone

05

Search says what it matched

Type and the table narrows down. Every hit is highlighted where it was found, and the counter says how much is left, so nobody has to guess why a row is showing.

yoursite.com/price-list

06

Change the look without writing CSS

Presets for the frame and the rows, then colours you can set one by one: headings, lines, stripes, the colour that answers a hover. Underneath there is a field for your own CSS, for the day you want something the settings do not cover.

WordPress › Appearance

07

Rename, hide, align and pin columns

Your sheet is for you; the table is for your visitors. Rename a heading without touching the sheet, hide a column you keep for yourself, push numbers to the right, pin the first column so it stays put while the rest scrolls.

WordPress › Columns and rows

08

When Google has a bad day, your page does not

The table on your page is served from a copy in your own database, so a visitor never waits for Google and never sees an error. The failed check shows up here, in your dashboard, where it belongs — with the history of the last checks.

WordPress › Sheet sources

09

Colours, filters and downloads

Rows that break a rule are coloured — here everything out of stock. Above the table, a filter your visitor can use. Under it, buttons for Excel, CSV and print, and a download contains exactly what is on screen: the rows left after filtering, and the columns you kept.

yoursite.com/price-list

10

A rule reads like a sentence

When Availability is Out of stock, paint the whole row. No formulas and no code. Colours are worked out on the server, so they are already in the page a visitor receives.

WordPress › Colour rules
